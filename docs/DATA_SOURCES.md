# Data sources

Every external dataset JAPAN LIVE uses is recorded here. Add or update an entry by
running `/data-source-audit` — an entry that has not been through that audit is not
cleared for use.

No credentials, tokens, or keys belong in this file.

## Status

No external data sources are integrated yet. V1 TOKYO TRAINS entries land here as they
are audited.
